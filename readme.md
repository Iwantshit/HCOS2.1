# HCOS: 一个开源的智能家居系统框架

**目前系统为简易的早期开发版本**

该项目旨在开发一个开源、灵活且轻量化的智能家居系统应用框架，可以根据需求组合/设计插件。

我们的愿景是以该系统为基础创建一个和谐开放的开源社区，为系统本身提供更丰富的插件支持以实现更多功能。

## 内核设计 

（自己看代码吧 更多内容会写在开发文档 specification.txt 中 这里只是简述

主要包括一个消息队列（优先队列）和部分资源管理系统，我们尝试以最简最轻量化的形式实现系统内核。

总线负责接收用户请求分发回传任务并处理资源管理器中的状态信息。

目前为多线程设计，大部分工作在主线程中进行，对少部分高频轮询/阻塞/操作使用线程池，系统大量使用异步接口以实现非阻塞的实时调度。

加入了request/response模式通信，后续考虑使用fastapi与前端进行通信。

现版本几乎不涉及任何网络协议设计。

## 插件设计

我们设计了一个通用的插件模板和模板校验函数 详见 core\plugins_base.py

提供了两个系统插件，用户登录管理和一个事件捕捉插件。

提供了两个可供参考的插件，一个用于集群控制LED灯(非持续性命令/低频)，一个用于控制单一设备温度传感器(持续性命令/高频轮询)。

需要通过.publish()发布消息控制插件或查看状态，插件需要使用.subscribe()订阅消息以接收命令。详见代码。
